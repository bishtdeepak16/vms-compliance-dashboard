LayerObjectNotes
Cloud Storagewms-outbound-raw-v2/shipping_package/NDJSON, sp_<tenant>_<facility>_<date>_<offset>.ndjson. API and partner/partner files share this prefix.

BigQuery · scansvms_portal2_raw → vms_portal2_view; Marketplace VMS raw; vms_daily_normalizedUNION ALL into one AWB-level registry with scan_type FORWARD or RETURN.
BigQuery · returnsraw_returns → returns_finalTEST FC removed, SKU read from JSON, same client eligibility rules.
BigQuery · complianceoutbound_vms_compliance_tbl_ops · return_vms_compliance_tbl_opssOne row per shipment or return with is_vms_scanned. Partitioned by dispatch_date and qc_date.
ServingHTML dashboard (Apps Script web app) · Users sheetReads the two compliance tables. Signs users in with Google and limits them to their FCs.
